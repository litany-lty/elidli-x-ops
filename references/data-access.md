# 数据访问、权限与费用边界

## 基础导入

JSON AccountInput 和显式 ColumnMapping 的 CSV 是必备入口。
CSV 映射记录规范字段到实际表头、常量、时间格式／时区、missing tokens 和 SourceRecord。
不要猜测某版 Analytics 导出的列名；列值与常量冲突时报错。
截图和公开页面提取须保留来源、采集时刻、字段定义及不能读取的部分。

公开搜索只形成样本，不证明完整账号覆盖、没有发布或受到限制。
目标账号的 user_id、完整 7／28 天材料、私有指标和声音样本在可靠材料取得前保持未知。

## 可选 X API

官方作者时间线、帖子查询、指标、Search、Counts、Trends 和 News 都是增强能力，不是基础改稿／公开新闻发现的前置条件。
读取私有作者指标前，用用户上下文取得授权用户 ID 并与目标账号核对；错号数据不得合并。
权限、费用、时间窗口、分页和 API 返回定义按实际端点记录。
配置中的付费预算不等于已经开通接口；默认新增付费额度为 0。

X Trends 只描述指定时刻与地区的结果；Counts 只描述固定查询和完整时间桶的匹配量。
X News 摘要是线索，仍需读取原始材料核验；result_count 或关联帖子 ID 不是讨论总量。

## 安全与操作

凭据使用宿主正式凭据机制，不写入技能、状态、fixture 或日志。
基础技能不发帖、不回复、不点赞、不自动互动，也不创建后台监控。
任何外部写入需要覆盖该对象与动作的明确授权。
