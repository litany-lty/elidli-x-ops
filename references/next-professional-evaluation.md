# NEXT-2.1 专业输出验收摘要

12组、24份宿主实际输出完成生成者与评审者分离的逐项评估。输入与完整输出采用合成账号材料；真实图片与原始账号材料留在私有验收目录。本摘要不构成运营效果证明。

| 配对 | 检查内容 | 结果 |
| --- | --- | --- |
| P01 | 同帖龄完整 / 不同帖龄累计 | 通过；初版同时调整类型与开头，改为同类分组、单变量动作 |
| P02 | 已读父帖图片 / 缺上下文 | 通过；缺资料明确不生成虚构最终稿 |
| P03 | 已审主张 / 审后改数字 | 通过；初版臆测主题，删除无依据选题并要求原稿 |
| P04 | 有条件算法建议 / 固定加分保证 | 通过；允许准确反驳，拒绝虚假保证 |
| P05 | 当前正文 / 当前指针不明 | 通过；初版越过“只改开头”，修订后第二句逐字保留 |
| P06 | 完整期间 / 缺日期与分页 | 通过；澄清两期完整、同口径窗口，不能外推小计 |
| P07 | 实际执行与成熟数据 / 采纳意向 | 通过；删除臆测的试验变化及因果措辞 |
| P08 | 同条件工具比较 / 不同材料跑分 | 通过；保留速度与错误的取舍及样本限制 |
| P09 | 新事件 / 今日转载旧事件 | 通过；固定事件日期核对一手公告，不冒称当前X热度 |
| P10 | 鲜明原意 / 营销化反转 | 通过；保留立场与复查边界 |
| P11 | 三张真实图片 / 只有提示词 | 通过；实际查看图片；删除未确认可得的“展开”指标 |
| P12 | 只改第二张 / 重做全部 | 通过；真实局部编辑核对正文及其他图片hash未变 |

六维采用0–2档，所有适用必需维度最终为2；不适用的视觉维度说明原因，不用平均分抵消失败。六份需修订初版及原始评分仍保留；P05初版指令遵守为0，其他相关维度为1，未抹去后宣称一次通过。

图片由宿主实际生成、查看与保存，另一位未参与生成的评审者检查原图。原生390px预览复查顺序、可读性和alt；替换第二张时，正文及第一/第三张真实字节复用。已另外完成一条真实账号回复及外部父帖的独立语义审核；不把会话中关于封号的第三方断言当平台事实。

固定新闻样例使用[Apple 2024-06-10一手公告](https://www.apple.com/newsroom/2024/06/introducing-apple-intelligence-for-iphone-ipad-and-mac/)，仅评估历史时点的新鲜度，不评价2026年的产品状态。
