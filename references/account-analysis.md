# 账号分析流程

## 输入边界

目标账号由用户指定即可；读取作者私有指标时才需要验证授权账号 ID。
优先使用已授权只读接口，其次是用户 JSON／显式映射 CSV／截图；公开索引只能形成样本。
导入前核对作者、账号 ID、来源、指标定义和覆盖，不把他人主页数据归到目标账号。

记录 requested window、cutoff、来源、观测到的最早／最晚帖子、原始数、去重数、页数、has_more、停止原因和指标可用数。
公开搜索不能升级为 source_window_complete；没有总量分母时不报覆盖百分比。

## 固定窗口与选择

- 发帖窗口按创建时刻进入最近 7 天／前 7 天、最近 28 天／前 28 天。
- 当前累计视图选 cutoff 前同一来源、范围和聚合窗口的最新整份快照。
- 报告写出快照的真实 captured_at 和帖龄；“截止前最新”不表示数据恰在 cutoff 一刻采集。
- 24h 视图选 `24h±2h` 最近观测，等距时选较早；帖子发布满 26h 才成熟。
- 可选 168h 视图选 `168h±12h`，发布满 180h 才成熟。
- 不为不同指标分别挑最大值或最后非空值。

按来源、范围、聚合窗口、帖子类型和请求分组统计有效数、中位数、总和、缺失数。
未知不变成 0；全是实际零才得到 sum/median 0。
比率仅用同一快照、同范围且分子分母有效的数据；零或缺失分母不生成比率。

相同语义键跨来源精确值冲突时，只排除该冲突指标；其他不冲突指标继续使用。
大 X ID 始终作为字符串；重复导入不得增加任何统计。

## Agent 报告

基于 AccountResult 生成：

1. 实际覆盖与数据齐全程度。
2. 1–3 项发布结构、内容特点或表现发现。
3. 少量代表帖，附具体正文／指标依据。
4. 每项发现的其他可能解释。
5. 一项可控制动作和下一次判断方法。
6. 当前仍不能回答的问题。

没有同龄历史快照时只描述当前累计分布，不声称“本周 24h 曝光下降”。
账号净增粉只能描述账号窗口变化，不能归因给具体帖子。
用户要求完整近况但只有样本时必须返回 partial；用户明确只分析样本时可在该范围 complete。
